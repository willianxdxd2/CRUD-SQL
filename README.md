Learning CRUD in SQL

My first experience with SQL, including an introduction to all SQL content and basic concepts. SQL was used to create the database for a pizzeria, along with the website.
The front end is available in the repository “Pizzaria_html_sql”.

Technologies

MySQL Workbench

MySQL

XAMPP

What I Learned

I gained an overall understanding of SQL and spent enough time practicing to get comfortable with it. I found it interesting how indexes can improve query performance. I learned CRUD operations and subqueries, created my own databases, and gained experience with table joins and auto-increment for creating unique IDs.

I also developed a solid understanding of how tables and databases should be organized in SQL.
